# rpgmts (RPG Maker TypeScript)
🏰 Toolkit for building RPG Maker MV/MZ plugins with TypeScript

> [!IMPORTANT]
> This project is currently more of a proof of concept and not fully stable. Use it at your own risk. The code is currently also an absolute mess!

## Packages in this repository

- [rpgmts](https://github.com/OfficialCRUGG/rpgmts/tree/main/packages/rpgmts) - Library and CLI for building RPG Maker MV/MZ plugins with TypeScript (in most cases you're probably looking for this!)
- [@rpgmts/types-mz](https://github.com/OfficialCRUGG/rpgmts/tree/main/packages/types-mz) - Type definitions for RPG Maker MZ

Type definitions for RPG Maker MV will follow in the future at a later point.
