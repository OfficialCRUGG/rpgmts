# @rpgmts/types-mz

🏰 Type definitions for RPG Maker MZ

> [!IMPORTANT]
> These type definitions were initially generated automatically from the RPG Maker MZ JavaScript codebase and are now checked and improved upon manually step by step. These may still contain inaccuracies and are a work in progress.

## Progress

We track progress in two separate metrics:
- Replacing `any` types with more specific types
- Manually checking all files and classes to see if all of their members are complete and present in the types.

You can see the current progress in the [PROGRESS.md file](https://github.com/OfficialCRUGG/rpgmts/blob/main/packages/types-mz/PROGRESS.md).
